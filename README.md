Projeto de Portfolio Pessoal

Este projeto tem como objetivo criar um portfólio visualmente atrativo e funcional, apresentando de forma clara os projetos e habilidades de um desenvolvedor. A estrutura do site foi pensada para oferecer uma navegação intuitiva e uma experiência de usuário dinâmica, com um layout responsivo que se adapta a diferentes tamanhos de tela.

Principais características:

Design Responsivo: O portfólio foi desenvolvido com foco em se adaptar a dispositivos móveis, tablets e desktops, garantindo uma experiência fluida em qualquer dispositivo.
Galeria de Projetos: Apresentação dos projetos de forma visualmente agradável, utilizando o efeito hover para destacar cada projeto, facilitando a interação do usuário.
Efeitos Interativos: Adição de animações suaves para transições e interações com imagens e camadas de conteúdo, criando uma sensação de dinamismo.
Estilo Personalizado: Utilização de variáveis de CSS para personalizar o esquema de cores, garantindo uma identidade visual consistente em todo o site.
Tecnologias utilizadas:

HTML5
CSS3
Design Responsivo com Media Queries
Efeitos de animação e transições com CSS
Este portfólio é uma representação do meu trabalho como desenvolvedor e foi projetado para destacar minha habilidade em criação de layouts interativos e design responsivo.
