Antonio Gomes

Sou um profissional em transição de carreira da área de Logística/Suprimentos para Tecnologia, com foco em desenvolvimento em Python e Data Science. Iniciei minha jornada com o curso Data Science Infinity School, onde adquiri sólidos fundamentos em Python e aprendi a utilizá-lo para resolver problemas práticos. Estou em constante aprendizado, explorando bibliotecas como Pandas e NumPy para análise de dados e TensorFlow para aprendizado de máquina.

Atualmente, estou aprofundando meus conhecimentos em Linguagem R para Data Science e Front-End, com ênfase em HTML, CSS e JavaScript, enquanto continuo explorando o potencial do Python e Data Science em projetos diversos. Estou sempre em busca de novos aprendizados e desafios que me permitam crescer como desenvolvedor e contribuir com soluções inovadoras.
